# KNOXPAD — записка в мире стримера

Окно-карта (Telegram Mini App) для бота [@KNOXPAD_bot](https://t.me/KNOXPAD_bot): зритель выбирает место на бумажной карте
округа Нокс, пишет записку — и после проверки модератором она появляется в игре стримера Project Zomboid.

Карта нарисована по данным карты мира Project Zomboid (The Indie Stone). Шрифты — Google Fonts (PT Sans Narrow, Caveat).
Страница ничего не хранит: записка уходит прямо в Telegram-бота.
